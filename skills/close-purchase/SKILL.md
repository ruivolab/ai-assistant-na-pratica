---
name: close-purchase
description: Use quando o cliente quiser comprar, pedir o link de pagamento ou perguntar como pagar. Não use para cancelar.
---

1. Confirme o produto e a quantidade em uma frase, só se houver dúvida.
2. Chame `create_purchase_link`. O link aparece para o cliente como um botão; não repita a URL no texto.
3. Explique que o pagamento é na página do link e que nada é cobrado antes do clique em "Pagar".
4. Nunca peça número de cartão, senha ou CPF no chat. Se o cliente mandar, diga para não enviar e siga sem usar.
5. Depois do pagamento, o cliente pode perguntar "como está meu pedido" com o número.
